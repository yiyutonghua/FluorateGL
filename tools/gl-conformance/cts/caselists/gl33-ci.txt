# == 裁剪规则 ==

# gl33-main.txt 为全量 KHR-GL33 mustpass（数千用例，软件渲染下 CI 耗时不可接受），
# 按以下规则裁剪出 300-800 个代表用例：

#  1. 只保留 `KHR-GL33.` 前缀的用例行（丢弃 KHR-GL30/31/32、GL45、ES 等组）；
#  2. 整组包含以下关键子组（组前缀匹配，如 `KHR-GL33.state_query.`）：
#       - state_query          （状态查询与枚举值正确性——翻译层核心）
#       - buffers              （缓冲区对象/VBO 语义）
#       - textures             （纹理目标/格式/采样语义）
#       - programs_and_pipelines（程序对象与管线——翻译层管线状态）
#       - shaders              （着色器编译/链接/内建变量）
#       - framebuffers         （FBO 语义——fbo surface 模式下尤为重要）
#       - vertex_arrays        （顶点属性绑定）
#       - uniforms             （uniform 定位/更新）
#       - draw                 （draw 调用与基元语义）
#       - sync                 （同步对象/fence）
#       - transform_feedback   （反馈缓冲）
#       - clip_distance / cull_distance、scissor、viewport、blend、depth_stencil、
#         multisample（若裁剪后不足 300 用例则按需追加）
#  3. 裁剪结果按原文件顺序排序，去重；
#  4. 目标规模 300-800 用例：先按上述子组整组包含，超出 800 时按组内用例
#     数由多到少截断（保留每组开头若干用例，保持组内覆盖）；不足 300 时
#     追加子组直至达标。
